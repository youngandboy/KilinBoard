# 智能桌面伴侣

`desk` 模式把现有硬件组合成一个桌面设备：

- 环境模式：温度、湿度、光照和舒适度
- 番茄钟：专注 / 短休息 / 长休息，LED 进度和蜂鸣器提醒
- 久坐提醒：ADXL362 检测桌面或椅子的持续无活动状态
- 网页控制：模式切换、开始/暂停/重置、确认提醒、静音

没有 LCD/OLED，环境数值仍显示在网页 Dashboard；板上 4 个 LED 作为状态和进度指示。

## 模式

| 模式 | 显示 | LED |
|---|---|---|
| 环境 | 温度/湿度/光照/舒适度 | 绿=舒适，红=偏热，蓝=偏冷，黄=干湿异常 |
| 番茄钟 | 阶段和剩余时间 | 4 个 LED 作为进度条；蓝=休息，黄闪=暂停 |
| 久坐 | 无活动分钟数 | 绿=有活动，黄=30 分钟预警，红闪=45 分钟报警 |

## 按键

| 按键 | 番茄钟 | 久坐 | 环境 |
|---|---|---|---|
| KEY1 | 开始/暂停 | 确认报警/重新计时 | 无动作 |
| KEY2 | 重置当前阶段 | 重置计时 | 无动作 |
| KEY3 | 切换模式 | 切换模式 | 切换模式 |
| KEY4 | 静音/取消静音 | 静音/取消静音 | 静音/取消静音 |

模式切换时 4 个 LED 会短暂闪烁。

## 默认时间

| 参数 | 默认值 |
|---|---:|
| 专注 | 25 分钟 |
| 短休息 | 5 分钟 |
| 长休息 | 15 分钟 |
| 长休息周期 | 每 4 个专注 |
| 久坐预警 | 30 分钟 |
| 久坐报警 | 45 分钟 |
| 活动阈值 | 相邻两次加速度差 80 mg |

ADXL362 只能判断桌面/椅子的移动，不是医疗级人体坐姿检测。

蜂鸣器默认静音；需要声音时按 KEY4 或执行 `desk mute 0`。久坐报警每次无活动周期只响一次，LED 保持红色提示，确认或检测到活动后复位。

## msh 命令

```text
desk                         # 查看状态
desk status                  # 同上
desk mode env|pomo|sit       # 切换模式
desk start                   # 开始番茄钟
desk pause                   # 暂停
desk reset                   # 重置当前模式
desk ack                     # 确认久坐提醒
desk mute 0|1                # 静音开关
desk beep                    # 短鸣
desk test <focus_s> <break_s> <sit_s>
```

`desk test` 用于快速验证，例如：

```text
desk test 10 5 10
desk start
```

表示 10 秒专注、5 秒休息、10 秒无活动触发久坐报警。测试结束后重新上电恢复默认时间。

## Dashboard

网页新增“智能桌面伴侣”卡片：

- 环境 / 番茄钟 / 久坐模式按钮
- 开始、暂停、重置、确认提醒、静音
- 当前阶段、剩余时间、已完成专注、无活动时间、舒适度

温度、湿度、光照、加速度和倾角继续显示在原有卡片中。

## NDJSON 字段

```json
{
  "mode": 1,
  "phase": 1,
  "remain": 1420,
  "cycles": 2,
  "sit": 0,
  "alert": 0,
  "mute": 0,
  "comfort": 1
}
```

| 字段 | 含义 |
|---|---|
| `mode` | 0 环境 / 1 番茄钟 / 2 久坐 |
| `phase` | 0 空闲 / 1 专注 / 2 暂停 / 3 短休息 / 4 长休息 |
| `remain` | 当前阶段剩余秒数 |
| `cycles` | 已完成专注次数 |
| `sit` | 当前无活动秒数 |
| `alert` | 久坐报警 |
| `mute` | 静音 |
| `comfort` | 0 未知 / 1 舒适 / 2 热 / 3 冷 / 4 干燥 / 5 潮湿 |

下行命令：

```json
{"t":"c","desk":"mode","v":1}
{"t":"c","desk":"start"}
{"t":"c","desk":"pause"}
{"t":"c","desk":"reset"}
{"t":"c","desk":"ack"}
{"t":"c","desk":"mute","v":1}
```

## Flash 说明

当前桌面伴侣构建关闭了应用侧 OTA 客户端（`svc_ota.c` / `msh_ota.c` 不参与编译），
以保留 Flash 余量。Bootloader 和原有分区仍保留，SWD 烧录流程不变。

因此本构建不提供 `ota` 命令，`tools/verify-ota.ps1` 只适用于 OTA 开启的构建。
